# Competitive Programming Hub


## Introduction

This is my personal competitive programming repository, used for saving solutions from contests as well as active practice.
This repository was created while preparing for the Polish Olympiad in Informatics (POI).
It serves as a general hub for everything one needs for competitive programming.
All solutions are my own work. Written in C++20.


## File Structure 

* `library/` - A library of all the algorithms, data structures and math concepts I know and use, implemented.
  * `├── data-structures/`
  * `├── algorithms/`
  * `└── math/`
* `problems/` - The solutions to the problems, divided by competition and furthermore by level.
  * `├── poi/`
    * `├── stage-1/`
    * `├── stage-2/`
    * `└── stage-3/`
  * `├── usaco/`

## References and Study Resources

[USACO Guide](https://usaco.guide) - Gold standard. Explains each algorithm thoroughly and provides problems scaling in difficulty.  
[Szkopul](https://szkopul.edu.pl) - Primary resource for the POI. Contains an archive of all past problems.  
[Codeforces](https://codeforces.com) - Best way to practice. Allows for contest simulation under time pressure.  
[StudyPlan](https://www.studyplan.dev) - The best C++ guide. For people who are not yet familiar with the language.
